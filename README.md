# Сайт-портфолио

Статичный сайт: `index.html`, `styles.css`, `app.js`, `config.js`. Весь текст, видео и ссылки сайт берёт из Google-таблицы при каждом открытии страницы. Код трогать не нужно.

## 1. Открыть доступ к таблице (один раз)

В таблице: **Настройки доступа → «Все, у кого есть ссылка» → Читатель**.
Без этого сайт не сможет прочитать таблицу и покажет заглушки.

## 2. Деплой на Netlify

Вариант без Git:
1. app.netlify.com → **Add new site → Deploy manually**.
2. Перетащи папку `portfolio-site` (не zip, а распакованную папку) в окно.
3. Site configuration → **Change site name**, чтобы получился адрес вида `имя.netlify.app`.

Обновлять файлы сайта нужно, только если меняется код. Контент меняется в таблице.

## 3. Как менять контент

- Вкладка **Settings**: все тексты, ссылки на шоурил и CV, почта, включение блоков (`yes`/`no`).
- **Clips**: короткие горизонтальные видео. `category` создаёт фильтры. Порядок строк = порядок на сайте.
- **Stats**, **Projects**, **Toolkit**, **Links**: строка = элемент на сайте, галочка `show` скрывает/показывает.
- Не переименовывай вкладки и первую строку с названиями колонок.

Видео-ссылки: YouTube, Vimeo, Google Drive (доступ по ссылке), прямые `.mp4`/`.webm`, Dropbox.

После правки в таблице обнови сайт. Google иногда отдаёт изменения с задержкой до пары минут.

## Блок «новое видео + VFX breakdown»

Настраивается во вкладке Settings, строки `show_latest` … `youtube_api_key`.
- `show_latest`: yes / no, показать или скрыть весь блок.
- Розовая карточка: `latest_url` (ссылка на YouTube), `latest_title`, `latest_date`. Просмотры обновляются сами раз в минуту.
- Правое видео: пока `breakdown_url` пустой, стоит заглушка. Вставь ссылку на mp4 (GitHub) или YouTube, и появится плеер.

## CV

CV лежит в репозитории GitHub `grigoriitvorogov/cv` и открывается по адресу https://cv.grigoriitvorogov.com.
Обновить CV: github.com/grigoriitvorogov/cv → Add file → Upload files → файл с тем же именем `CV_Grigorii_Tvorogov.pdf`.
Деплой на Netlify не нужен. Через 2–3 минуты новая версия появится на сайте и по короткой ссылке.
Ссылки grigoriitvorogov.com/cv и старая /cv.pdf тоже ведут на актуальное CV.

## Видео

Видео и превью лежат в репозитории GitHub `grigoriitvorogov/portfolio` (адреса вида https://grigoriitvorogov.github.io/portfolio/имя.mp4).
Новый клип: загрузи mp4 и jpg в этот репозиторий и впиши ссылки во вкладку Clips. Деплой на Netlify не нужен.

## Если подключишь другую таблицу

Открой `config.js` и замени `sheetId` на ID новой таблицы (часть ссылки между `/d/` и `/edit`).
